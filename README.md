# Presentación web — Taller 4 de Estadística Básica

Sitio estático listo para GitHub Pages. Incluye 15 ejercicios, procedimientos y 16 gráficas tomadas del desarrollo del taller.

## Publicar en GitHub Pages

1. Descomprime el ZIP.
2. Crea un repositorio en GitHub, por ejemplo `estadistica-basica-taller4`.
3. Sube **el contenido de esta carpeta** a la raíz del repositorio: `index.html`, `styles.css`, `app.js`, `assets/`, `README.md` y `.nojekyll`.
4. En el repositorio, entra en **Settings → Pages**.
5. En **Build and deployment**, selecciona **Deploy from a branch**, `main`, carpeta `/(root)` y guarda.
6. Abre la dirección pública que GitHub Pages indique.

## Controles

- Flechas izquierda y derecha: navegar entre diapositivas.
- Inicio / Fin: primera o última diapositiva.
- Barra inferior: índice, anterior, siguiente y pantalla completa.
- En móvil: desliza a los lados.
- Tecla `M`: abrir índice; `F`: pantalla completa.

La portada deja `Nombre y apellido` como dato por completar. Cámbialo en `index.html` antes de publicar.

No utiliza frameworks, bibliotecas de interfaz ni servicios externos. Las gráficas están incluidas localmente. Puedes abrir `index.html` sin conexión.

Los datos son los ejemplos didácticos del taller, no registros empíricos reales. Las expresiones de curtosis muestral corresponden al estimador corregido utilizado en Excel.
